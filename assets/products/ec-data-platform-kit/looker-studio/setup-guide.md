# Looker Studio 接続手順

## このディレクトリに入っているもの

| ファイル | 中身 |
|---|---|
| `views/*.sql` | ダッシュボードが参照する BigQuery のビュー定義（47個） |
| `field-definitions.md` | 各ビューの列一覧。Looker Studio 側のフィールド名を合わせる先 |
| `setup-guide.md` | この手順書 |

**レポート本体（.pdf や .json のようなファイル）は含まれていません。**
Looker Studio のレポートはクラウド上の成果物で、ファイルとして配布する手段がないためです。
下の手順で1回組み立てれば、以降はテンプレートとして複製できます。

## なぜビューを挟むのか

Looker Studio から GA4 の `events_*` を直接参照すると、
グラフを操作するたびに全期間がスキャンされ、クエリコストが跳ね上がります。

**ビューを挟むと、参照範囲と粒度を SQL 側で固定できます。**
表示も速くなり、フィールドの意味も1箇所で管理できるようになります。

## 手順

### 1. ビューを作成する

`views/` から使いたいものを選び、`${PROJECT}` と `${DATASET}` を自社の値に置き換えて実行します。

```bash
# まずドライランでスキャン量を確認（課金されません）
bq query --dry_run --use_legacy_sql=false < views/<選んだファイル>.sql

# 問題なければ実行
bq query --use_legacy_sql=false < views/<選んだファイル>.sql
```

ビューを置くデータセットは、生データとは分けることを勧めます（例: `mart`）。
権限を分けられるので、閲覧者に生データへのアクセスを与えずに済みます。

### 2. Looker Studio でデータソースを追加する

1. Looker Studio で新しいレポートを作成
2. データを追加 → **BigQuery** コネクタを選択
3. プロジェクト → データセット → 手順1で作ったビューを選択
4. 「追加」

:::message
ここで「カスタムクエリ」ではなく**ビューを選ぶ**のが要点です。
カスタムクエリはレポート内に SQL が埋め込まれてしまい、修正のたびに
レポートを開く必要が出てきます。ビューなら BigQuery 側で差し替えられます。
:::

### 3. フィールドを整える

`field-definitions.md` に各ビューの列を書いてあります。
Looker Studio 側で以下を確認してください。

- **日付列**が「日付」型として認識されているか（文字列のままだと期間フィルタが効きません）
- **金額列**の集計方法が SUM になっているか（既定で AVG になることがあります）
- **比率列**（`*_pct` / `*_rate`）が AVG になっているか（SUM だと合計が100%を超えます）

### 4. コストを抑える設定

| 設定 | 場所 | 効果 |
|---|---|---|
| データの更新頻度 | データソース設定 | 既定15分。日次で十分なら12時間に伸ばす |
| BI Engine | BigQuery 側 | 予約すると表示が速くなりクエリ課金も減る |
| 期間のデフォルト | レポート設定 | 「過去28日」など短めに。全期間は避ける |

### 5. テンプレートとして再利用する

レポートが完成したら、右上の共有 →「レポートのリンクを取得」→
URL 末尾の `/edit` を `/preview` に変えたリンクがテンプレート配布用になります。
複製すると、データソースだけ差し替えて同じ構成を再現できます。

## つまずきやすい点

**グラフに「(not set)」が並ぶ**
ビュー側で `IFNULL` を当てていない列があります。ビュー定義を修正してください。

**期間フィルタが効かない**
日付列が文字列型のままです。ビュー側で `PARSE_DATE('%Y%m%d', event_date)` を通します。

**表示が遅い**
生データを直接参照していないか確認してください。ビュー経由になっていれば、次は BI Engine を検討します。

**数値が合わない**
セッションの定義を疑ってください。GA4 のセッション数は
`user_pseudo_id` と `ga_session_id` の組み合わせで数える必要があります。
`sql/` の該当クエリと突き合わせて確認してください。
