## EC データ分析 実務ガイド ― 25の課題と、その解き方

「在庫が余る」「返品が多い」「送料無料ラインをいくらにすべきか」——
EC を運営していると出てくる具体的な困りごとを、**GA4 と BigQuery のデータで判断する**ための
実務ガイドです。全25本。

### こんな方に

- GA4 は入れているが、数字の見方が分からないまま放置している
- 施策の効果を「なんとなく上がった気がする」で終わらせている
- 外部のエンジニアや制作会社に依頼したいが、何を頼めばいいか整理できていない
- レポートは見ているが、そこから次の打ち手に繋がっていない

エンジニアでなくても読めるように書いています。
SQL は全文を載せているので、そのまま社内のエンジニアや外注先に渡せます。

### 収録している25の課題

**在庫・商品**
- 在庫回転率から死に筋を特定する
- 返品率をカテゴリ別に分析して原因を切り分ける
- 商品ページの写真枚数と CVR の相関を検証する
- レビュー数と売上の関係を定量化する
- 粗利率を商品×チャネル別に自動計算する

**価格・販促**
- 送料無料ラインを購買データから決める
- セール施策の効果を before / after で比較する
- クーポンのカニバリゼーション（既存客への値引きになっていないか）を検証する
- 価格変更が CVR と売上に与えた影響を因果推論で切り分ける
- ギフト需要を時系列で読んで在庫計画に反映する

**集客・チャネル**
- 受注データと GA4 を結合して正確な売上帰属を出す
- メルマガのクリックから購入までを追跡する
- Amazon 広告と自社 EC を統合してチャネルミックスを最適化する
- 越境 EC の多言語計測を国別に正しく集計する
- 同梱チラシの効果をオフライン CV 連携で測る

**基盤・計測**
- Shopify × GA4 でデータが合わない問題を解決する
- BASE・STORES・Shopify の計測精度を比較する
- 楽天・Amazon・自社 EC の売上を BigQuery に集約する
- カスタムピクセルで高精度なエコマース計測を実装する
- Webhook × Cloud Functions でリアルタイムに取り込む
- チェックアウト拡張機能のイベントを分析する
- サイト速度と CVR の関係を CrUX データで検証する
- 物流コストの上昇分を商品別に可視化する
- CS 問い合わせを集約して商品改善に繋げる
- 定期購入の解約予兆を行動ログから検知する
