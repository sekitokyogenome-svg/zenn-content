# EC データ分析 実務ガイド ― note 有料マガジン

I系列25本を note で売るための原稿一式です。
生成は `python3 scripts/build_note_magazine.py`。**冪等なので何度実行してもよい。**

| ファイル | 中身 |
|---|---|
| `articles/NN-<slug>.md` | note に貼る原稿25本（公開順に採番） |
| `INDEX.md` | 収録一覧・無料部分の割合（**自動生成。手で編集しない**） |
| `magazine-description.md` | note のマガジン紹介文。そのまま貼れる |
| `README.md` | この運用手順（**書き下ろし。再生成しても保持される**） |

## note に貼る手順

投稿先アカウント: **https://note.com/engawakun**

1. `INDEX.md` の順に `articles/NN-*.md` を開く
2. **先頭の H1（`# ...`）を note のタイトル欄に入れ、本文からは消す**
3. 残りを本文に貼る
4. `<!-- ここから有料 -->` の位置に note の有料ラインを引き、**マーカーの行は消す**
5. 価格を980円に設定し、マガジンに追加する
6. 末尾のCTAはそのまま残す（マガジンと受託への導線）
7. **`urls.json` にURLを追記して再生成する**（下記）

## 投稿したら urls.json にURLを書く

告知文とZenn側の導線は、ここにURLが入るまで出ません。
未確定のURLを公開記事に埋めると404を配ることになるためです。

```jsonc
{
  "magazine": "mXXXXXXXX",   // マガジンID または完全URL
  "articles": { "I-01": "nXXXXXXXX", "I-02": "" }
}
```

**IDだけ書けば済みます。** アカウント（engawakun）はスクリプトが持っているので、
`https://note.com/engawakun/m/` の部分は不要です。完全URLを貼っても構いません
（`?from=share` のようなクエリは自動で落ちます）。

別アカウントのURLを書くと**エラーになって無視されます**。
公開済み22記事に他人のリンクを撒く方が、リンク切れより害が大きいためです。

```bash
python3 scripts/build_note_promo.py   # 告知文のURLが埋まる
python3 scripts/bulk_cta.py           # Zenn の EC系25本に note 導線が付く
```

無料部分は全記事で「はじめに」＋本題セクション1つまでに収めてあります（全体の7〜33%）。
症状と「何を見るべきか」までを読ませて、実際の SQL と判断基準から先を有料にする設計です。

## Zenn 記法の変換について

note のエディタは Zenn 記法を解釈しません。生成時に以下を変換済みです。

| 元 | 変換後 | 理由 |
|---|---|---|
| `:::message` | 引用（`>`） | note に該当の記法が無い |
| 表（`\| a \| b \|`） | 「**項目**：値」の箇条書き | **note に表組みが無く、貼るとパイプ記号が並ぶ** |
| `## 関連記事` | 除去 | Zenn 記事への内部リンクのため |
| 記事末尾のCTA | note 用に差し替え（`utm_source=note`） | リンク先と文言が違う |
| frontmatter | 除去し、title を H1 へ | note にメタ情報の欄が無い |
| 装飾用の `---` | 除去 | note で区切り線にならない |

**残る手作業**: note はマークダウンの一括貼り付けを完全には解釈しません。
見出し（`## `）とコードブロック（```）は貼った後に note 側の書式で当て直す必要があります。
CTA のリンクは裸の URL にしてあるので、note 側で自動リンクになります。

## 絶対にやらないこと

**この25本を Zenn で無料公開しない。** 同じ内容が無料で読めれば誰も買いません。

遮断は `articles/` 側の `note_only: true` で行っています。
`scripts/queue_drafts.py` がこのフラグを見て公開キューの対象から外します
（J系列の `book_only: true` と同じ仕組み）。
フラグを消すと次回の `queue_drafts.py` 実行で公開対象に戻ってしまうので、消さないでください。

## 執筆・生成について

制作には生成 AI を利用しています。そのうえで SQL は構文検証にかけ、
構成と説明を確認したうえで公開しています。

**この記載と「検証したのは構文まで」という但し書きは、全25本の末尾CTAに自動で入ります**
（`scripts/build_note_magazine.py` の `NOTE_CTA`）。手で足す必要はありません。
note の規約（読者に具体的な価値を提供する）と、返金要求への備えの両方のためです。
文言を変えるときは `NOTE_CTA` を書き換えて再生成してください。
