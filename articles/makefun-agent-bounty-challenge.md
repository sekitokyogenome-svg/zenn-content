## はじめに

AIエージェント向けの懸賞プラットフォーム「make.fun」に、自分のAIエージェントを参加させてみました。課題は「ゲームを作る」「高速なCSVリーダーを書く」「未上場プロトコルをランク付けするダッシュボードを作る」など。賞金はUSDCで、Solana上のエスクローに事前にロックされています。参加は無料です。

2026年11月21日に登録して、22日までに7件提出しました。全件結果待ちの段階ですが、「エージェントに稼がせる」系の話は成功談ばかりが回るので、提出までの実務で何に引っかかったかを先に書いておきます。

## 最初の誤算：いつものAIセッションでは出られない

make.funの提出物は、成果物のコードだけではありません。課題によっては「その成果物を作ったAIセッションのトランスクリプト（記録）」の提出が必須で、記録とコードの対応が機械的にチェックされます。

ここで問題になるのがセッションの出自です。ホスト型のAIアシスタント（アプリ側が管理するセッション）は handed_over（引き渡し）扱いになり、有償順位の対象外でした。つまり「普段使っているAIに作らせて提出」がそのままでは通らない。

そこで構成をこうしました。

- 記録用ハーネス：Gemini CLI（セッションログがそのまま提出用トランスクリプトになる）
- 接続：AI StudioのAPIキー経由（GCPのVertex AIではない）
- むび（普段のアシスタント）側は、課題選定・プロンプト設計・独立検証・提出チェックに専念

「作るAI」と「監督するAI」を分けたのが、この挑戦の基本形です。

## 提出ゲートで実際に踏んだもの

提出はキットのCLIで bundle → check → submit と進みます。checkを通らないと提出できません。踏んだ順に書きます。

### 1. record必須の見落としで1作目が死んだ

大型のゲーム課題（プール$1,666）で、1作目は完成後に「この課題は `makefun record` による封印記録が必須」と判明し、提出不可になりました。制作コスト約$3.5〜5.5がそのままサンクコストです。

教訓は単純で、**制作前に RULES で record の要否を確認する**。これ以来、着手前の確認項目に入れました。

### 2. 自動収集を切らないと他人のセッションが混ざる

bundleの自動収集（discover）を使うと、同じマシンにある別アプリのセッションまで取り込んで提出不可になります。`--no-discover --no-family` を付けて、対象セッションを明示指定するのが必須でした。

### 3. 出力にタイムスタンプを入れたら落ちた

再提出したゲームは一度だけ落ちました。原因は build-summary.json に入れた生成時刻（createdAt）。run の決定性チェックは「main を2回実行して出力が完全一致すること」を見るので、時刻や乱数が混ざる出力は通りません。

### 4. authored率という概念

トランスクリプトとコードの対応から「エージェントが書いた行の割合」が測られます。下限は課題により30%のところもあれば80%のところもありました。スターターコードをそのまま残すと main ファイルが「自作でない」と判定されます。

## 提出した7件と、数字の現実

提出済みは次の7件です（いずれも結果待ち）。

| 課題 | 形式 | 状況 |
|---|---|---|
| ステルスゲーム | 審査制 | check 15項目パスして提出 |
| 強盗ゲーム | 審査制 | 共通エンジン再利用で約14分完走 |
| GTA風オープンワールド | 審査制 | 開発フェーズ暫定レート 0.9845（12勝0敗） |
| tiny stack VM | 自動採点 | 練習セット40/40、スコア1,000,000 |
| CSVリーダー高速化 | 自動採点 | 参照実装と完全一致、約2.0倍速 |
| 倉庫番ソルバ | 自動採点 | 全問最適解、スコア1,000,000 |
| token radar（データ分析） | 審査制 | プール$1,325。詳細は別記事に書いた |

期待値の話もしておきます。プラットフォーム全体の支払い総額は $16,655（1,076アカウント）ですが、**中央値は $3.53** です。平均で語ると見誤ります。大金は $1,000級のトップヘビーなプールの上位から出ていて、トップの獲得者は12勝で $888 でした。だから戦略は「小さい課題を複利で回しつつ、大型プールに本命を置く」になります。1件あたりの制作コストは推定 $1.5〜9 程度に抑えています。

コスト面の実績も書いておくと、AI Studio側の11月分表示は料金 ¥3,339 でした。ただし全額がGCPクレジットで相殺され、請求は ¥0 です（2026年11月23日確認）。クレジットが尽きたらこの前提は崩れるので、台帳で損益を追っています。

## 本業と重なるジャンルが一番おもしろい

7件の中で一番手応えがあったのは、データ分析・ダッシュボード系（token radar）でした。封印されたデータセットを読み解いてモデルを作り、ダッシュボードに仕上げる形式で、普段のGA4/BigQueryの分析業務と筋肉の使い方がほぼ同じです。

## まとめ

- エージェントに稼がせる系の仕組みは実在するが、提出ゲートの実務（トランスクリプト、record、決定性、authored率）が本体
- 数字の中央値は地味。複利の効く共通部品と、検証の型を作れるかどうかが勝負
- 結果は12月上旬から順次出るので、確定したら続編で損益まで含めて書きます
